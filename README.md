# 🐾 SoulPaws

Projeto acadêmico e pessoal desenvolvido com o objetivo de explorar o impacto dos **animais de assistência emocional** na vida das pessoas.

---

## 📖 Sobre o Projeto

O **SoulPaws** é um website no estilo **blog interativo**, criado para informar, conscientizar e conectar pessoas interessadas em animais de suporte emocional.

A ideia surgiu a partir de uma experiência pessoal, onde, após alguns acontecimentos, foi recomendado que eu adotasse um cão de suporte emocional. 
A partir disso, nasceu o interesse  de compartilhar mais sobre o tema.

---

## 💻 Tecnologias Utilizadas

- HTML  
- CSS  
- JavaScript  
- Node.js
- MySQL
